## Part B — plugin/skill friction, version-independent (#ask-89596ae5)

Grounded in real daily-maintenance runs. Each tied to something that happened.

1. **Source-completeness guard has no source list** (biggest). The guard says report
   the status of every requested source, but the skill never defines WHICH sources a
   daily sweep covers. On the 06-20 brief I swept Gmail/Calendar/Drive/Jira, declared
   it complete, and silently omitted Slack AND GitHub — two of the user's most active
   sources. The guard catches "you reported a source empty"; it does NOT catch "you
   forgot the source exists." A canonical per-wiki source registry the sweep iterates
   would have prevented it. Caught only because the user flagged it, twice.

2. **Routing Notes is read but never bootstrapped.** Pre-flight ③ reads
   MY-INTEGRATIONS.md "Routing Notes" and applies it as session defaults — but the
   auto-created MY-INTEGRATIONS.md is just an ingest-log table with no Routing Notes
   section and nothing prompting you to make one. The skill consumes a section it
   never tells you to write. Learned it existed only when the user asked "isn't there
   a save mechanism?" Until then my conventions lived only in agent-memory, invisible
   to the skill.

3. **No daily-maintenance orchestration + no brief-rotation convention.** "Daily
   maintenance: ingest all sources + surface a brief + clean up old briefs" isn't a
   defined op. §10/§11 exist but the ingest-all + cleanup orchestration is improvised.
   Brief lifecycle undefined: where old briefs go, when to archive. I invented
   "_archive/briefings/ + archive yesterday's daily brief" and repeat it on faith.

4. **Connected-tool output floods context, no built-in bounding.** Two Slack searches
   + one Gmail get_thread each blew the tool token cap and spilled to sandbox files
   (102K/84K/80K). Hierarchy says "use connected tools eagerly" with no result-size
   discipline → eager + unbounded = repeated overflow parsed out of files by hand.

5. **Normal use monotonically inflates lint noise.** Every daily brief and lint report
   is a dated page with no inbound links → permanent new orphan. Orphans 7→14 over a
   few days of just doing the job. Same for _archive: snapshot-before-update means
   editing the same page daily (manual-test-case-versioning, pod-structure) drops a
   new _archive/<slug>-<date>.md each time, no cleanup convention. The wiki's own
   hygiene metrics degrade as a function of using it correctly.

6. **_status.md reads as current but is a start-of-session snapshot.** Header
   "Last checked: <timestamp>" looks authoritative. Told me "50 issues / 14 orphans";
   live lint minutes later said 28🟡/2🔴. I surfaced the stale number first. Nothing
   signals it's frozen at session-start.

7. **Freshness-first doesn't reconcile with batch ingest.** "Before writing/updating a
   page, sweep connected tools for newer primary sources." A daily sweep touches ~8
   pages → literally a tool-sweep per page. I batch-swept once and used judgment, which
   "respect cost" permits — but that clause contradicts the hard "before writing...
   sweep" rule, so you must pick which instruction to disobey.

8. **privacy:true has gone meaningless.** "When in doubt mark private," and ~everything
   internal qualifies, so every page I create is private:true. A flag that's always on
   stops discriminating — can't drive export decisions anymore.

Smaller:
- wiki-search semantic is mandated first, but for exact tokens (KSR/issue numbers, $
  figures) grep is what works and I default to it; the hierarchy oversells semantic for
  lookup-by-identifier.
- Proactive behaviors (ambient-capture "want me to add it?", post-task offer) are tuned
  for interactive chat; in an autonomous maintenance run they'd be noise. The skill
  doesn't distinguish interactive PM chat from autonomous maintenance.

**Net theme:** strong on per-operation discipline (orient, snapshot, provenance), weak
on the recurring multi-source maintenance loop — no source registry, no brief lifecycle,
no bound on tool output, hygiene counters that only ratchet up. That loop is where the
real time goes.
